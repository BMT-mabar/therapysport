# TherapySport - ד"ר דוד גרבר (Dr. David Garber) 🚴‍♂️

קליניקת פרימיום לפיזיוטרפיית ספורט, שיקום רוכבי אופניים, אבחון ביומכני ומדרסים בהנהלת **ד"ר דוד גרבר (DPT, PT)** בזיכרון יעקב.

## 🚀 תכונות האתר (Features)
- 🌊 **לוגו TherapySport מקורי**: שילוב הלוגו הרשמי עם הגלים מכרטיס הביקור והקובץ המקורי.
- 🎬 **וידאו באנר בלופ (`DJI_0783.mp4`)**: סרטון גלישה/רחפן איכותי הרץ ברקע אוטומטית.
- 📸 **גלריית 8 תמונות רצה (Slider Carousel & Marquee)**: סרגל תמונות נע אינסופי + סליידר תמונות אינטראקטיבי מהקליניקה.
- 🩺 **אבחון סימפטומים אינטראקטיבי ("איפה כואב לך?")**: עדכון דינמי של כפתורי האבחון והקישורים לוואטסאפ בהתאם לאזור הנבחר ולשפה.
- ⚡ **פרוטוקול 4 השלבים לשיקום וביצועים**: עיצוב דינמי ועשיר עם כרטיסי Glassmorphic ואפקטים גרפיים.
- 📚 **סקשן מאמרים מקצועיים (`#articles`)**: תובנות רפואיות ומדריכים קליניים עם חלונית קריאה מלאה (Modal).
- ⭐ **Google Reviews בלחיצה**: קישורים ישירים לדירוג 5.0 ולכרטיסי הביקורות בגוגל.
- 🌐 **תמיכה דו-לשונית מלאה**: מעבר מהיר ומהודק בין עברית לאנגלית (RTL/LTR).
